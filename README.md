# Tunebox-v-0.2
I'm just making a music player with a nice aesthetic. I would really appreciate it if you joined as a beta tester or to help me develop and provide ongoing support for the app.

## Novedades 1.7
- Letras en línea (LRCLIB): se descargan solo con internet, no se guardan en el dispositivo. Las letras locales (.lrc/.txt) tienen prioridad.
- Búsqueda en YouTube cuando una canción no está en el dispositivo (Ajustes > YouTube: clave gratuita de la API de YouTube Data v3). Se reproduce con el reproductor oficial incrustado, con sus anuncios, y solo mientras el video está visible.
- Barra del reproductor estilo Spotify (dispositivo, letra, cola) y canciones del dispositivo en la Biblioteca.
- Botón "Buscar actualizaciones" (GitHub Releases).
