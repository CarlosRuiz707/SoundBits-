# Tunebox

Reproductor musical Android con biblioteca local, catálogo online y diseño inspirado en Spotify.

## Qué incluye
- Interfaz tipo Spotify con fondo oscuro, verde premium y navegación clara.
- Biblioteca local con reproducción, cola, búsquedas y listas.
- Catálogo online con fuentes compatibles y reproducción en app.
- Reproductor modal, mini-player, portada y controles estilo streaming.

## Branding
- Nombre visual: Tunebox
- Estilo: Spotify-inspired dark UI
- Base tecnológica: Android + WebView + Java

## Notas
- El proyecto mantiene la funcionalidad original de TuneBox.
- La visual se adapta a una experiencia más premium y moderna.
